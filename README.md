# Authentication & Authorization Application

Система аутентификации и авторизации пользователей с разграничением прав доступа и демонстрационным бизнес-приложением «Система электронного документооборота».


## Функциональность

### 1. Взаимодействие с пользователем
- Регистрация новых пользователей с автоматическим назначением роли `User`
- Вход в систему по email и паролю
- Просмотр и редактирование профиля
- Мягкое удаление аккаунта (данные сохраняются)
- Выход из системы

### 2. Система разграничения прав доступа 
- Управление ролями и разрешениями
- Связь пользователей с ролями
- Проверка прав доступа через декораторы и миксины
- API для административного управления ролями

### 3. Бизнес-приложение (Mock)
- Документы с уровнями доступа (public, restricted, confidential)
- Проекты с фильтрацией по участию пользователя
- Отчёты (только для Admin и Moderator)
- Фильтрация данных в зависимости от роли пользователя

## Технологии

- **Backend:** Django 
- **База данных:** SQLite
- **Аутентификация:** Django Session Authentication
- **Хэширование паролей:** PBKDF2 + SHA256 (встроенный механизм Django)
- **Шаблоны:** Django Templates
- **Управление зависимостями:** Poetry

## Установка и запуск

### Предварительные требования

- Python 3.10+
- Poetry (менеджер пакетов)

### 1. Клонирование репозитория

git clone https://github.com/AvedyanAV/application_for_authentication_and_authorization/tree/develop

### 2. Установка зависимостей
poetry install

### 3. Активация виртуального окружения
poetry shell

### 4. Применение миграций
python manage.py makemigrations
python manage.py migrate

### 5. Создание суперпользователя
python manage.py createsuperuser

### 6. Заполнение тестовыми данными
python manage.py seed_rbac

### 7. Запуск сервера разработки
python manage.py runserver

## Тестовые аккаунты

- **Admin**  |  **admin@example.com**  |  **Admin123!** (Полный доступ ко всем ресурсам, управление ролями)
- **Moderator**  |  **moderator@example.com**  |  **Moderator123!** (Просмотр всех пользователей, расширенный доступ к документам)
- **User**  |  **user@example.com**  |  **User123!** (Только свой профиль, доступ к своим документам и проектам)

## Роли по умолчанию

### Admin (Администратор)
Полный доступ ко всем ресурсам системы.
Разрешения:
- users.view_self, users.view_all
- users.edit_self, users.edit_all
- users.delete_self, users.delete_any
- roles.view, roles.manage

### Moderator (Модератор)
Расширенные права просмотра, доступ к restricted-документам.
Разрешения:
- users.view_self, users.view_all
- users.edit_self
- users.delete_self
- roles.view

### User (Пользователь)
Базовые права — только свой профиль, свои документы
Разрешения:
- users.view_self
- users.edit_self
- users.delete_self

## Бизнес-приложение: Система электронного документооборота

Демонстрационное приложение имитирует работу системы электронного документооборота с применением созданной системы.

**Важно: бизнес-данные хранятся в памяти (Mock), таблицы в БД не создаются. При перезапуске сервера данные сбрасываются.**

## Сущности

### Документы (Documents)
- **public** — доступны всем пользователям
- **restricted** — доступны Admin и Moderator
- **confidential** — доступны только Admin

### Проекты (Projects)
- **public** — доступны всем пользователям
- **restricted** — доступны Admin и Moderator
- **confidential** — доступны только Admin

### Отчёты (Reports)
- **public** — доступны всем пользователям
- **restricted** — доступны Admin и Moderator
- **confidential** — доступны только Admin

## Правила доступа
- **Admin**  |  **Все документы**  |  **Все проекты**  |  **Все отчёты**
- **Moderator**  |  **public + restricted + свои документы**  |  **Свои проекты**  |  **Все отчёты**
- **User**  |  **public + свои документы**  |  **Свои проекты**  |  **403 Forbidden**
